## <img src="https://api.iconify.design/lucide:star.svg?color=%23eab308" width="22" height="22" align="center" /> Featured Projects

Here are some of my key projects demonstrating full-stack development, mobile apps, clean architecture, self-hosted deployment setups, and AI integration:

### <img src="https://api.iconify.design/lucide:package.svg?color=%233b82f6" width="20" height="20" align="center" /> [Orbis](https://github.com/mertmnvv/orbis) — Restoran & Kurye Takip Appliance
A fully self-hosted, secure, and private restaurant delivery tracker. Includes a web dashboard for restaurant management, a mobile application for couriers, and a print-bridge service.
- **Architecture:** Monorepo, Restaurant-local Docker setup, Local database instance syncing to cloud directory, secure communication.
- **Key Features:** RLS (Row Level Security), real-time courier position tracking, cash/POS tracking, automatic route optimization, multi-delivery, watchtower for auto-updates.
- **Tech Stack:** 
  `Next.js 14` `Expo (React Native)` `Supabase (PostgreSQL, Realtime, GoTrue)` `Docker` `Cloudflare Tunnels` `Tailscale` `Zod` `Zustand`

### <img src="https://api.iconify.design/lucide:zap.svg?color=%23eab308" width="20" height="20" align="center" /> [QuestFit](https://github.com/mertmnvv/questfit) — Next-Gen Gamified Fitness & Wellness Companion
A gamified health, diet, and training mobile companion that bridges the gap between fitness diaries and habit-building mechanics, powered by Groq Generative AI.
- **Key Features:** Gamified progress/consistency levels, daily randomized quests, activity/step streaks, muscle fatigue heatmap, AI nutrition macros calculator (Llama 3.3 70B), and AI custom equipment-aware workout generator.
- **Tech Stack:** 
  `React Native (Expo CNG)` `Zustand (AsyncStorage offline-first)` `Firebase (Firestore, Auth)` `Groq AI (Llama 3.3)` `expo-sensors` `i18next`

### <img src="https://api.iconify.design/lucide:sparkles.svg?color=%23a855f7" width="20" height="20" align="center" /> [Astrifer](https://github.com/mertmnvv/astrifer) — Custom Star Map Configurator
An e-commerce platform allowing users to generate astronomically accurate sky charts for any date, time, and location in the world. Sold as digital shares or high-quality physical prints.
- **Key Features:** Precise astronomical calculations, customizable templates, Admin dashboard for order/template management, Puppeteer worker generating 300 DPI high-quality print outputs.
- **Tech Stack:** 
  `Next.js 14 (App Router)` `TypeScript` `Tailwind CSS` `astronomy-engine` `Firebase Admin SDK` `Puppeteer`

### <img src="https://api.iconify.design/lucide:graduation-cap.svg?color=%2310b981" width="20" height="20" align="center" /> [Vespera](https://github.com/mertmnvv/vespera) — YKS Study Companion & Pomodoro
A social study companion platform designed for national university entrance exams (TYT-YDT). Features shared study rooms, real-time sync, calendars, and task management.
- **Key Features:** Real-time study rooms, live seconds-left synchronization, task board, stats and logs.
- **Tech Stack:** 
  `Next.js` `React` `Tailwind CSS` `Firebase (Firestore, Authentication, Realtime)` `Flutter (Mobile Version)`

### <img src="https://api.iconify.design/lucide:building-2.svg?color=%23ef4444" width="20" height="20" align="center" /> [CaddeLocale](https://github.com/mertmnvv/CaddeLocale) — Clean Architecture Backend
A clean and structured enterprise .NET Core application built with clean architecture standards.
- **Architecture:** Clean Architecture separation (Core, Application, Infrastructure, Web/API).
- **Tech Stack:** 
  `C#` `.NET Core` `Clean Architecture`
